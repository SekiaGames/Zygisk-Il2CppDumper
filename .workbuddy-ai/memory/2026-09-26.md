# 2026-09-26

## 修复 GitHub Actions Build 失败

- 现象：Actions 报错 `This request has been automatically failed because it uses a deprecated version of actions/upload-artifact: v3`，另有 ubuntu-latest 将迁移到 Ubuntu 26 的 notice。
- 原因：`.github/workflows/build.yml` 中三个 action 都是 2023 年的旧大版本（checkout@v3 / setup-java@v3 / upload-artifact@v3），v3 运行在已 EOL 的 Node 16 上，GitHub 已强制拒绝执行。
- 修复（`.github/workflows/build.yml`）：
  - `actions/checkout@v3` → `@v7`
  - `actions/setup-java@v3` → `@v6`（setup-java v4 及以下已被官方标记弃用）
  - `actions/upload-artifact@v3` → `@v7`
  - `runs-on: ubuntu-latest` → `runs-on: ubuntu-24.04`（显式固定镜像，避开 ubuntu-latest 迁移到 Ubuntu 26 带来的不确定性；本项目 AGP 7.4.2 / Gradle 7.5 较老）
  - 输入引用 `github.event.inputs.package_name` → `inputs.package_name`（workflow_dispatch 推荐写法）
- 未改动：构建命令、sed 替换逻辑、artifact 名称与路径。
- 遗留建议：artifact 目前只上传 `out/magisk_module_release/` 目录（不可直接刷入 Magisk），可考虑同时上传 `out/*.zip`（如 `zygisk-il2cppdumper-v1.2.0-release.zip`）。
- 环境要点：module/build.gradle 需要 NDK 25.2.9519653 + CMake 3.22.1，由 AGP 自动下载。
